Veloci for the dinosaurs, Code for what you'll do for a month. VelociCode is a game jam for students, hobbyists, artists, designers, and first-timers. We announce a theme, you build a game around it, and we play everything together at the end.

  • Any engine

    Godot, Unity, Unreal, the web, a Python script. If it runs, it counts.

  • One whole month

    Not a sleepless weekend. Enough time to learn something new and still finish.

  • Built in public

    A live theme reveal at kickoff, playtest nights along the way, and a showcase where everyone plays your game.
